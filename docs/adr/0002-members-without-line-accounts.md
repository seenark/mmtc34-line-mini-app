# Members may exist without a LINE account

Identity is the LINE userId, but some classmates order by telling an Admin in the group chat. Importing past Campaigns from pasted messages will also create entries for people who never opened the app. So an Admin can create an Unlinked Member (nickname only) and place Orders for them. When the person joins later, an Admin links their LINE account to the existing Member instead of creating a duplicate. The LINE userId is therefore optional on a Member, not its key.
